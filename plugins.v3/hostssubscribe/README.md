# 定时订阅Hosts

订阅远程 hosts 规则，定时更新系统 hosts 文件，加速网络访问。

## 功能

- 支持填写一个或多个订阅地址，每行一个，格式为普通 hosts 文本（`ip host1 host2 ...`）。
- 启用插件后立即拉取一次并写入系统 hosts，之后按配置的 cron 周期定时更新。
- 支持手动 hosts 配置，与订阅内容合并后一起写入。
- 订阅失败或 hosts 行格式无效时，错误信息展示在配置页，并推送系统通知。
- 关闭插件时自动恢复系统 hosts（移除本插件写入的部分）。
- 提供远程命令 `/hosts_subscribe` 立即手动更新一次。

## 配置

| 配置项 | 说明 |
| --- | --- |
| 启用插件 | 总开关 |
| 订阅地址 | 每行一个 hosts 订阅地址 |
| 更新周期（cron表达式） | 定时更新周期，默认 `0 3 * * *`（每天 3 点） |
| 手动hosts（可选） | 手动补充的 hosts，格式 `ip host1 host2 ...` |
| 错误信息 | 只读，展示订阅失败或无效的 hosts 行 |

## 注意

- hosts 格式为 `ip host`，中间有空格。
- 容器运行则更新容器 hosts，非宿主机。
- 网络故障导致所有订阅地址获取失败时，保留现有 hosts，不会清空。
